🌐 Como Criar Seu Site 100% Gratuito

Guia completo para iniciantes usando GitHub Pages

Início Ideias Sobre Contato Política

📌 Dá mesmo para criar um site grátis?

Sim. Hoje qualquer pessoa pode criar um site profissional sem pagar nada, utilizando o GitHub Pages, que hospeda seu site gratuitamente e gera um link público.

✔ Não precisa cartão
✔ Hospedagem grátis
✔ Ideal para blogs e renda online
✔ Aceita Google AdSense

🚀 Passo 1: Criar sua conta no GitHub

O GitHub é uma plataforma onde você armazena os arquivos do seu site (como HTML e CSS).

🔗 https://github.com

Clique em Sign up, crie seu usuário, confirme o e-mail e faça login.

📁 Passo 2: Criar um repositório

O repositório funciona como a pasta principal do seu site.

✔ Nome simples
✔ Público (Public)
✔ Clique em Create repository

📤 Passo 3: Enviar os arquivos do site

Envie todos os arquivos HTML do seu site.

Sempre deixe o arquivo principal com o nome index.html.

🌍 Passo 4: Ativar o GitHub Pages

Este passo coloca seu site no ar.

Vá em Settings → Pages, escolha a branch main e salve. O GitHub mostrará o link do site em alguns segundos.
